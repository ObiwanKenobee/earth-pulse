# 🌎 Product Thesis

Most software describes what has happened.

A planetary digital twin aims to help users understand:

> **What is happening, what could happen next, and what different interventions might change.**

The platform therefore connects:

```text
Observe
   ↓
Understand
   ↓
Simulate
   ↓
Decide
   ↓
Act
   ↓
Measure
   ↓
Learn
   ↺
```

The frontend is the interface through which this loop becomes understandable and usable.

```ts

  id: string
  name: string

  resolution?: string
```

# 🧪 Epistemic Integrity

A planetary simulation must distinguish between different levels of certainty.

Every major output should identify whether it is:

```text
OBSERVED
MODELED
ESTIMATED
FORECAST
SCENARIO
ILLUSTRATIVE
```

Example:

```text
Water Stress
Observed: 62%

2035 Scenario
Modeled: 71%

Confidence
Medium
```

This distinction is foundational.

A visually impressive simulation that confuses **model output with reality** becomes a dangerous decision interface.
